# 海畔 · 客户端

Flutter 实现的 Android 课表与学业信息客户端，完整功能与技术说明见仓库根目录 [README](../README.md)。

## 技术要点

| 项目 | 实现 |
|---|---|
| 框架 | Flutter / Dart 3 |
| 状态 | Riverpod |
| 网络 | Dio + Cookie 会话，自托管 WebSocket 隧道 |
| 存储 | SharedPreferences 结构化缓存 + 文件系统日志 |
| 原生 | Kotlin 通道：Keystore、本地提醒、桌面组件、FileProvider |

## 功能与技术实现

| 模块 | 功能 | 实现 |
|---|---|---|
| 课表 | 周视图、切周、学期切换、实践课、当前周高亮 | 教务课程列表归一化为本地模型，按周分页渲染 |
| 成绩 | 学期切换、绩点与加权平均、成绩构成 | 学期分组计算，单科展开明细，本地换算项标注估算 |
| 考试 | 倒计时、考场座位、考试提醒 | 按时间排序，AlarmManager 本地排程，通知直达详情 |
| 学业 | 修读分类、学分进度、通识拓展学分 | 按课程类别汇总已修 / 在读 / 未修 |
| 排名 | 学年学期区间、成绩性质、统计范围 | 组装查询参数后请求教务接口 |
| 空教室 | 校区 / 楼栋 / 类别、周次 / 星期 / 节次多选 | 多时段拆分为单时段请求并合并，收藏本地持久化 |
| 情侣课表 | 6 位配对码、我 / TA / 合看、共同空闲 | 一对一绑定，字段白名单同步，快照 7 天内计算空闲 |
| 提醒与组件 | 上课 / 考试提醒、两种桌面组件 | 本地课表排程，RemoteViews 渲染并跟随系统明暗 |
| 个性化 | 明暗模式、字体大小、背景风格 | 统一设计令牌与页面过渡 |
| 离线 | 缓存优先、断网可读 | `cache_` 前缀键按模块存储，请求失败时回落 |
| 隐私 | 学号脱敏、本地日志、Keystore 凭据 | 日志写盘前脱敏，敏感凭据加密存储 |
| 登录 | 统一身份认证、多因子 | RSA 加密密码、验证码预检、短信 / 企业微信验证 |
| 更新 | 检查更新、下载安装 | 读取 Releases 最新版本，比较版本号与构建号 |

> 非官方客户端。数据来自本人账号在教务系统中可见的信息，仅用于个人课表与学业管理。
