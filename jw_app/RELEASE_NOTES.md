# 海畔 v1.0.0 发布说明（历史）

> 本文仅保留 v1.0.0 首发记录；当前版本与更新日志见根 [README.md](../README.md) 与 [docs/release_notes_v1.0.1.md](../docs/release_notes_v1.0.1.md)。

广东海洋大学教务系统第三方客户端首发版。

## ✨ 主要功能

- **课表**：周视图，左右滑切换周次，课程按颜色区分，今日高亮，自动标记当前周
- **成绩**：按学期查看成绩 / 绩点 / 加权平均，支持打开成绩构成（平时·期末）明细
- **考试**：考试安排按时间排序，显示距今天数倒计时
- **学业**：修读进度（已获得 / 最低修读要求学分），按课程类别查看通过 / 未修 / 在读明细，GPA 按学分加权稳定计算
- **绩点排名**：按统计范围与学年学期查询，一目了然
- **空教室**：按校区 / 楼栋 / 场地类别筛选，支持周次 / 星期 / 节次多选，可收藏常去教室并查看使用情况
- **个人信息**：年级 / 院系 / 专业 / 班级
- **离线可用**：课表 / 成绩 / 考试 / 学业均有本地缓存，断网也能查看已加载数据
- **检查更新**：发现新版本直接下载 APK 并安装
- **贴心体验**：顶部通知、首启功能介绍、明暗模式、全局字体大小可调

## 🔒 隐私

- 账号密码仅保存在本机用于登录学校教务系统，不会上传到任何服务器
- 本应用为学习交流用途的非官方客户端，请以教务系统官方信息为准

## 🖥 支持的平台

- Android 8.0+（APK）
