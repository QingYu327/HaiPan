# 海畔 v1.0.2 更新日志

## 新增功能

- 情侣课表（Beta）：支持 6 位配对码一对一绑定，提供「我 / TA / 合看」三种视图；合看时同一时段左右分栏，双方课表快照均在有效期内时计算当天共同空闲。仅同步课名、节次、地点与周次，不同步学号、姓名、教师与成绩，任一方解除后绑定关系即失效。
- 校外访问：新增自建加密通道，校内自动直连、校外自动切换；公网通道按学号授权。
- 自动检查更新：启动时自动检查新版本，发现更新后引导进入更新页。

## 登录与网络

- 登录改为原生表单直连统一身份认证，不再先渲染网页。
- 通道与认证页并行准备、重复请求合流，缩短登录耗时。
- 支持验证码预检、短信与企业微信多因子验证。
- 校园网内登录不再校验公网准入；准入被拒时先复核校内直连，避免弱网误判。
- 网关、限流等返回的裸 403 不再被判定为未开通公网通道。
- 修复非白名单学号被误判为网络错误的问题。
- 非白名单用户登录时明确提示权限原因，并引导使用校园网或联系管理员开通。

## 体验与界面

- 所有操作结果统一使用应用内灵动岛提示。
- 成绩、考试、学业、课表、排名、空教室、收藏、检查更新、日志清空与导出等操作补齐反馈。
- 修复已是最新版本仍提示更新的问题；版本标识统一为「版本号 + 构建号」。
- 关于页介绍与技术栈信息更新。
- 情侣课表入口增加 Beta 标识，页面内提供可关闭的功能稳定性提示。

## 日志与本地占用

- 运行日志支持调试级详细输出，并可设置保留天数。
- 日志页与调试页的设置入口不再重复；关闭详细日志后不再记录或展示调试级条目。
- 日志容量提升，详细日志开关与保留天数的变更均会记录，便于排查。
- 本地占用统计覆盖应用私有目录内的全部数据，并按日志、离线缓存、会话与其他文件分类展示。
- 本地占用不足 1 MB 时按 KB 显示，避免小体积数据展示为 0。
