## v1.0.1
# 海畔 v1.0.1 更新日志

> 适用于 `1.0.1` 正式线；构建号见 Release 标签（如 `v1.0.1+4145`）。安装包请从官网或 GitHub Releases 获取。

### 本次构建（4145）
- 关于页介绍更新为在线查询学业情况、空教室与排名信息，同时保留离线课表与课程提醒
- 成绩、考试、学业、课表、排名、空教室查询、收藏、检查更新、日志清空/导出等操作补齐灵动岛反馈
- 运行日志页新增「输出详细日志」「日志保留」设置，与调试页共用；关闭详细日志后不再记录/展示调试级条目
- 日志容量提升，开关与保留天数变更本身也会留痕，便于排查
- 官网使用文档、注意事项页窄屏改为汉堡菜单，并移除页面中硬编码的版本号与构建号

### 校外访问
- 新增自建加密隧道：校外经通道访问教务，校内自动直连、不做多余转发
- 公网通道按学号授权，需联系管理员开通；受线路影响速度慢于校园网

### 登录
- 改为原生表单直连学校统一身份认证，不再先渲染网页，减少页面跳转
- 通道与认证页并发准备、重复请求合流，登录速度明显提升
- 认证跳转统一使用 HTTPS；简化多因子短信验证的换票流程
- 修复非白名单学号被误判为网络错误的问题
- 准入校验轻量化：只按学号查询放行结果，不传递登录态

### 体验
- 启动时自动检查更新，发现新版本直接弹窗引导进入更新页
- 所有提示统一走应用内灵动岛，移除页面内小字错误条
- 登录页新增可关闭的校园网使用提示
- 关于页更新技术栈与开源许可信息

### 其他
- 清理废弃的网页登录分支、探针脚本与测试代码
- 优化隧道连接复用，消除端口残留导致的连接失败

### 致谢
- 感谢 X 反馈的准入误判问题。

修复内容：
- 校园网直连不再校验公网通道名单，仅公网用户需要开通；
- 网关、限流等返回的裸 403 不再被误判为「未开通公网通道」；
- 准入被拒时会复核校内直连，弱网误判不再挡住校园网用户。

- 覆盖安装即可保留课表缓存与登录状态
