## v1.0.1

### 校外访问
- 新增自建加密隧道：校外经通道访问教务，校内自动直连、不做多余转发
- 公网通道按学号授权，需联系管理员开通；受线路影响速度慢于校园网

### 登录
- 改为原生表单直连学校统一身份认证，不再先渲染网页，减少页面跳转
- 通道与认证页并发准备、重复请求合流，登录速度明显提升
- 认证跳转统一使用 HTTPS；简化多因子短信验证的换票流程
- 修复非白名单学号被误判为网络错误的问题
- 准入校验轻量化：只按学号查询放行结果，不传递登录态

### 体验
- 启动时自动检查更新，发现新版本直接弹窗引导进入更新页
- 所有提示统一走应用内灵动岛，移除页面内小字错误条
- 登录页新增可关闭的校园网使用提示
- 关于页更新技术栈与开源许可信息

### 其他
- 清理废弃的网页登录分支、探针脚本与测试代码
- 优化隧道连接复用，消除端口残留导致的连接失败

### 致谢
- 感谢 2024\*\*\*\*1227 同学反馈「校园网下误报未开通公网通道」的问题。
  根据其反馈的复现路径，本版定位到客户端把校园网误判为校外、以及裸 403 被当成名单拒绝
  两处缺陷并修复：校园网直连不再校验公网名单，准入拒绝时也会现场复核校内直连。
